    - 14 options available

    - e.g., "6 x 9 inches"

## 🔧 TROUBLESHOOTING

### **/catalogs/ shows 404:**
```
→ Settings → Permalinks → Save Changes
→ Clear browser cache (Ctrl+F5)
→ Try incognito mode
```

### **Subtitle not showing:**
```
→ Make sure subtitle is filled
→ Check on single page only (not archive)
→ Clear cache
→ Hard refresh
```

### **SVG logo has black blocks:**
```
→ Should NOT happen with our SVG
→ Clear browser cache
→ Check browser is modern
→ Try different browser
```

### **Colors not teal:**
```
→ Hard refresh (Ctrl+Shift+R)
→ Clear all caches
→ Disable cache plugins
→ Wait 5 minutes
```
