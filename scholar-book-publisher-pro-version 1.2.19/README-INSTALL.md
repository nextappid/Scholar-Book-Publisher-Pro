## 🔧 TROUBLESHOOTING

### **/catalogs/ shows 404:**
```
Solution:
1. Settings → Permalinks → Save Changes
2. Clear browser cache (Ctrl+F5)
3. Try incognito mode
```

### **Teal colors not showing:**
```
Solution:
1. Hard refresh (Ctrl+Shift+R)
2. Clear all caches
3. Wait 5 minutes for CSS to load
```

### **Fonts not loading:**
```
Solution:
1. Check internet connection
2. Google Fonts needs internet
3. Clear browser cache
```

### **Default values don't appear:**
```
Note:
- Only for NEW books
- Existing books keep saved values
- Add NEW book to see defaults
```
