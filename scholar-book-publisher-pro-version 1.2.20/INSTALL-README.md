## ✅ QUICK INSTALLATION (5 MINUTES)

### **STEP 1: Upload Plugin**
```
WordPress Admin → Plugins → Add New → Upload Plugin
Select: scholar-book-publisher-pro.zip
Click: Install Now → Activate
```

### **STEP 2: Flush Permalinks** ⚠️ **CRITICAL!**
```
Settings → Permalinks → Save Changes
(Just click Save, don't change anything)
```

### **STEP 3: Verify**
```
✓ Visit: yoursite.com/catalogs/
✓ Check: Books menu appears in admin
✓ No 404 errors
```

## 📚 ADD YOUR FIRST BOOK

### Go to: **Books → Add New**

**Required Fields:**
- Title
- Cover Image (max 1MB)
- Description (use formatting toolbar!)
- Author(s)
- Publisher Name & City
- Publication Date
- ISBN
- Language
- Access Category (Open/Closed)

**Optional:**
- DOI
- Price
- PDF (if Open Access)

**Click Publish!**

## 🛠️ TROUBLESHOOTING

### **/catalogs/ shows 404**
```
Solution: Settings → Permalinks → Save Changes
Clear browser cache (Ctrl+Shift+R)
```

### **Cover upload fails**
```
Check: File size < 1MB
Format: JPG or PNG only
```

### **Theme toggle not working**
```
Clear browser cache
Check JavaScript console for errors
```

### **Filters don't work**
```
Disable other plugins temporarily
Clear browser cache
Test in incognito mode
```
