=== INSTALLATION ===

1. Upload scholar-book-publisher-pro.zip via WordPress admin
2. Activate plugin
3. Go to Settings → Permalinks → Save Changes (CRITICAL!)
4. Visit yoursite.com/catalogs/ to verify
5. Add your first book
